# Information Architecture

## 1. Parent website
### Main landing page: `/`
- JH Studio Design & Development identity
- Brand statement: “Architecture that connects.”
- Subtle animated architectural linework
- Two clear division choices:
  - Knitted Architecture → `/knitted-architecture`
  - Real Estate Development → `/real-estate-development`
- Real Estate Development marked **Coming Soon**
- Parent-company footer

### Parent-company footer
- About JH Studio
- Our Team
- Our Divisions
- Contact
- Social media links
- Copyright / legal links when details are supplied

These parent-level sections should explain JH Studio as a whole, not replace the detailed Knitted Architecture pages.

## 2. Knitted Architecture
Suggested routes:
- `/knitted-architecture` — division landing page
- `/knitted-architecture/philosophy` — philosophy and five principles
- `/knitted-architecture/projects` — searchable/filterable project portfolio
- `/knitted-architecture/projects/[slug]` — individual project details
- `/knitted-architecture/process` — design approach/process
- `/knitted-architecture/studio` — current team and studio information
- `/knitted-architecture/contact` — inquiry path, if a separate contact page is useful

Division navigation:
**Home | Philosophy | Projects | Process | Studio | Contact**

## 3. Project portfolio
Filters:
- All Projects
- Ongoing
- Completed
- Concepts & Design Studies (only if content is supplied)

Each card should show:
- Cover image or drawing
- Project title
- Project type/category, if supplied
- Location, if supplied
- Status
- A clear link to project details

## 4. Project detail page
Use a reusable template. Include only sections with supplied content:
- Project title and status
- Short overview
- Location / type / year, where known
- Design brief or challenge
- Design concept
- Plans, elevations, sections, sketches, renderings, photographs
- Design development sequence, if materials exist
- Relevant principles of Knitted Architecture
- Related projects
- Inquiry call to action

Never invent missing data. Hide empty fields or show a deliberate “details to be added” state only during private development—not as public-facing filler.

## 5. Real Estate Development
- Division introduction
- Clear **Coming Soon** label
- Short approved description
- Optional contact link to JH Studio
- Do not imply that a development portfolio or active investment opportunity exists until the owner supplies details.

## 6. Team
- Launch with current team only.
- Keep people in a data collection/object so new team members can be added later.
- Suggested fields: name, role, short biography, portrait, professional links (all optional).
- Never fabricate team names, titles, qualifications, or biographies.

## 7. Shared elements
- Parent-company footer
- Logo/wordmark
- Responsive navigation
- Consistent design tokens
- Accessibility and reduced-motion support
